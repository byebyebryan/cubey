# Retained studies

Active applications are listed in the [project portfolio](../README.md). This tree holds
bounded experiments, research, auditions and their regression helpers. A retained
script/result is not a supported startup path, a current default or a fresh-checkout
asset promise. No study runs as an implicit build/setup step.

- [Fluid 2.5D / Terrain Water lineage](fluid_25d/README.md).
- [Terrain landscape, material and wider-water studies](terrain/landscapes/README.md).
- [glTF saved-water / depth / cinematic auditions](gltf_viewer/README.md).
- [Cloud reference](cloud/README.md): explicit opt-in TerrainEngine comparison,
  separate from the production atmosphere-hosted cloud layer.
- [Terrain hydrology](terrain/hydrology/README.md), [reference](terrain/reference/README.md)
  and [ShaderToy reference](terrain/shadertoy/README.md) remain distinct older labs.

The [relocation map](relocations.json) records the 2026-10-15 cleanups, including
multiple former names that now resolve directly to one canonical study file.
Historical media recipes and sealed narrative snapshots retain their original identifiers
and bytes; old commands describe their original revision. Current front doors
link the supported replacement. Optional ignored outputs, model caches and the
qualified SynxFlow private binary were not moved or deleted.
