# Terrain landscape studies

These are retained calibration, material, capture, coverage and saved-water
experiments. Use [Terrain](../../../projects/terrain/README.md) for the current
application contract, and its [tools](../../../projects/terrain/tools/README.md)
for maintained source/site preparation. No solver or model generation runs
implicitly when opening Terrain.

- [Former development/qualification README](development_history.md): preserves
  dated measurements, accepted limitations, rejected trials and prior defaults.
- [Prepared-world wider water](world_wide_water_v1.md).
- Coverage/world studies: `study_terrain_world_v1.py`, `study_terrain_atlas_v1.py`.
- Captured-water/LOD studies: `study_wider_water_v1.py`, `study_world_wide_water_v1.py`.
- Current-state admission/selection evidence: `review_prepared_landscapes_v1.py`,
  `review_landscape_hardening_v1.py`, `review_landscape_first_use_v1.py`.
- Material/readability and wide-view trials retain their original named runners
  and corresponding tests in this directory.

Reproduction needs each study's exact optional assets/runtime. Frozen protocols
must reject changed inputs rather than silently relabel old results. Capture
shell scripts may open windows; select headless checks explicitly. Moving these
files does not promote pending visual choices or change terrain/water resolution.
The [relocation map](../../relocations.json) records old paths.
