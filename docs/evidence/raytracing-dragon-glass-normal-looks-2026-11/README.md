# Dragon glass normal visual comparison evidence

See the [visual results](../../notes/raytracing-dragon-glass-normal-looks.md).
This is the appearance follow-up requested after the Q1 probe experiment.

[Published interactive visual report](http://starship:8787/reports/8fab40dff6b178dcdf49d6c45c0c2ea3b9483bf14dd789b71c952b7262bc2668/)
contains the five paired views and original image links.

- `comparison.json` contains the five paired views, original PNG hashes,
  exact capture commands, statuses, paired binary/shader identities and fidelity
  controls. The report bundle uses byte copies of the rendered PNGs.
- `validation.json` records source/asset preservation, capture and documentation
  checks. It does not mark the smooth policy optically qualified.
- `report-delivery.json` records the published report URL, verified asset bytes
  and browser controls. The internal report is separate from the public site.
- `make_report.py` and `report-template.html` reproduce the dedicated report
  bundle. Wipe, toggle, blink and SVG crops all use original image assets.

The ignored run root is
`outputs/raytracing/dragon-glass-normal-looks-20261114/`. `starting-state.json`
and `original-source/` preserve the pre-comparison working tree. The paired
`source-geometric/`, `source-smooth/`, `build-geometric/`, `build-smooth/` retain
the private integration and complete binaries/shader sets. `captures/` holds
raw HDR/status buffers, PNGs, metrics, logs and receipts for all thirteen runs.

The integration is generated by
`projects/raytracing/tools/compare_dragon_normals.py`. The normal-policy choice
is a private compile-time constant; it is not an ordinary CLI/native option.
The geometric pilot matches the ordinary renderer exactly. Full-HD geometric
PNGs have only one-code-per-channel maximum differences against retained Q0.1;
the more complete fidelity statistics are in the manifest.

The following commands reproduce or verify retained captures in the frozen run
root. Existing receipts are reused only after their identity and artifact
hashes match:

```sh
rtk proxy uv run --no-project --no-build projects/raytracing/tools/compare_dragon_normals.py --suite pilot --output outputs/raytracing/dragon-glass-normal-looks-20261114
rtk proxy uv run --no-project --no-build projects/raytracing/tools/compare_dragon_normals.py --suite views --output outputs/raytracing/dragon-glass-normal-looks-20261114
rtk proxy uv run --no-project --no-build projects/raytracing/tools/compare_dragon_normals.py --suite isolated --output outputs/raytracing/dragon-glass-normal-looks-20261114
```

The first preparation of a new run requires a preserved `original-source/` and
`starting-state.json` before `--suite prepare`. Existing private build directories
are never overwritten. Their `build.json` files retain toolchain commands and
foundation-library hashes.

All captures are diagnostic appearance previews, including any finite image
with retained transport flags. No candidate promotion, new source-model repair,
Q2/Q3 or public-site publication is claimed.
