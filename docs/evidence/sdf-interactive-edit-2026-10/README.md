## Reproduction and retention

Build `cubey_project_sdf_cached_stroke_study` in the recorded Release build.
The two serial harnesses are `projects/sdf/tools/interactive_edit_loop.py` and
`projects/sdf/tools/rounded_stroke_loop.py`. Their phase names and complete
commands are in the receipts. Give each rerun a fresh output directory; the
harness refuses to overwrite evidence. For example:

```sh
cmake --build build/release --target cubey_project_sdf_cached_stroke_study -j 4
python3 -B projects/sdf/tools/rounded_stroke_loop.py geometry \
  --inputs outputs/sdf/interactive-edit-loop-20261031/rounded-inputs-v3/inputs.json \
  --output outputs/sdf/replay-rounded-geometry
```

Most exact-cache runs use `--edit-cache-no-dump`; this still reads and compares
every active raw R16 word in memory. Representative native dump files and their
exact hashes are listed in [retention.json](retention.json). Retain the receipts,
inputs, source-pinned logs, retained source replays, executable and shader bundle.
The qualified executable embeds the absolute shader directory
`/home/bryan/code/cubey/build/release/projects/sdf/shaders`; preserving the binary
alone is insufficient after build cleanup. Keep that runtime directory or
restore its exact bundle at that path, or rebuild and requalify a relocated
executable. No cleanup, deduplication or non-SDF artifact changes occurred.

## Superseded probes and limitations

The pre-qualification `service-v1` scored a publication frame index rather than
the completed replacement latency; final service uses the strict elapsed
66.667 ms deadline. `rounded-admission-v1` exposed a fixture alias: mutating its
edited prefix also mutated its base fixture. The detached-base negative test
is fixed in the final 23 checks. `rounded-geometry-pilot-v1` exposed the retained
Cached near-workspace-face ambiguity; zero-tool controls and the regular versus
diagnostic roster were established before final timing. These probes are not
accepted results or evidence of a runtime correction.

No public mode/default, source format, authored content, smoothing contract,
allocator, brush/undo UI, controller integration, XR acceptance, push or site
publication is included. `qualified-v1` stops the combined stroke service route
on Guardian's failed throughput gate.
