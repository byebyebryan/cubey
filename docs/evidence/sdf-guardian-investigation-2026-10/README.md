# Guardian query investigation evidence

Date: 2026-10-28. See the
[decision and measurement notes](../../notes/sdf-guardian-investigation.md).

`summary.json` contains grouped per-run p95 ranges, query-weighted CSG work,
native image differences and provenance. `timing.json` preserves commands and
per-run metrics for 324 accepted timing runs. `qualification.json` records 620
independent checks, 28,800 uninstrumented comparisons and 230,400 paired content
rays. `workload.json` contains separate primary/normal/shadow counters and payload
hashes; CSG instruction visits are not GPU ISA instruction counts.

`images/` contains sixteen native 320x180 opaque captures. `images.json` records
pixel differences and exhaustion checks. `memory-properties.txt` is the live
device memory-type excerpt. `provenance.json` pins runtime/source/shader/fixture
identity and verifies 181 pre-existing shader/content files remain byte-identical.
`rejected-exact-clip.json` explains why the exact 0.499 interval was excluded.

The accepted inner interval has half extent 0.4995, retaining an empty margin
outside the actual 0.499 source clip. GPU-local placement is an opt-in native
ablation; it does not change the general buffer allocator or sampled default.
Candidate full-HD Guardian timings remain unmeasured.

## Reproduction

Build `cubey_project_sdf` with the Release preset, then run one owned GPU process
at a time:

```sh
python3 projects/sdf/tools/investigate_guardian.py workload --output OUTPUT
python3 projects/sdf/tools/investigate_guardian.py workload --tight-root --output OUTPUT
python3 projects/sdf/tools/qualify_guardian_investigation.py --workload-root OUTPUT --output QUALIFICATION
python3 projects/sdf/tools/investigate_guardian.py timing --output OUTPUT
python3 projects/sdf/tools/investigate_guardian.py timing --tight-root --output OUTPUT
python3 projects/sdf/tools/investigate_guardian.py timing --residency-run --output OUTPUT
```

Output directories must be fresh. The current runner exercises the accepted
padded interval; historical rejected receipts are not regenerated by these
commands. Private native flags are `--comparison-stage`,
`--comparison-tight-root` and `--comparison-residency`.

Raw frames, query inputs, binary ray/counter payloads, profiler CSVs and logs are
retained locally under `outputs/sdf/guardian-investigation-20261028/`. A timing
CSV/log archive is included with the HTML export. Raw per-ray binary payloads
remain local; their hashes are in this pack. They use little-endian records:
32-byte ray results and 208-byte counter records. Counter layout is
`totals[3][4], bins_low[3][4], bins_high[3][4], walk[3][4], hit[4]`, with phases
primary, normal and shadow. The raw receipt describes record strides.

These are local diagnostic results, not default adoption, a new editor, physical
desktop acceptance, a GitHub push, or public showcase media.
