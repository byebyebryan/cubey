# Evidence

This directory retains compact review artifacts for promoted foundation
milestones. These files complement executable tests and ignored local review
packs; they are not golden-image tests.

- [Terrain backdrop foundation](terrain-backdrop-foundation/README.md): the
  isolated terrain and glTF proof-consumer captures, source provenance, image
  hashes, and regeneration command for Terrain V1.

- [October foundation and documentation qualification](foundation-2026-10/README.md):
  source-pinned runtime scopes, the documentation gate, configure variants and
  preservation results. Historical runtime qualification is distinguished from
  the later documentation-only checks.
