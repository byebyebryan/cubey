milestones and source-pinned investigations. These files complement executable tests and ignored local review
packs; they are not golden-image tests.

  early subjects, nine selected native stills, retained source/input fingerprints
  and explicit static-capture and visual-acceptance boundaries.
- [Architectural SDF diorama drafts](../notes/sdf-diorama-drafts-2026-11.md): the
  subsequent mill, observatory and courtyard, six selected native views and
  retained authoring/visual corrections; the user selected the observatory.
- [Selected observatory detail passes](../notes/sdf-observatory-detail-2026-11.md):
  eight new native stills, original-draft comparison, local section scope and
  retained modeling corrections; later user placement findings led to cleanup.
- [Observatory cleanup](../notes/sdf-observatory-cleanup-2026-11.md): nine native
  comparison/inspection views, serialized-pose support checks and retained
  enlarged-base candidates; retained after the shift to sculptural art direction.
- [Sculptural clay drafts](../notes/sdf-sculptural-drafts-2026-11.md): nine native
  carved/uncarved/alternate views of sleeper, spirit and refuge; source-pinned
  inputs, retained correction rounds and explicit early-draft limitations.

- [Terrain backdrop foundation](terrain-backdrop-foundation/README.md): the
  isolated terrain and glTF proof-consumer captures, source provenance, image
  hashes, and regeneration command for Terrain V1.

- [October foundation and documentation qualification](foundation-2026-10/README.md):

- [SDF tracing/cache comparison](sdf-tracing-comparison-2026-10/README.md): implemented

- [SDF source shader selection](sdf-shader-selection-2026-10/README.md): published
