The newly exposed failure

Exact reproduction, explicit rejection

The 2,048-SPP run repeats byte-for-byte. Binary search finds 1,335 samples clean and 1,336 failing. The production budget and doubled budget both record invalid-medium status 16, with no event/query/shadow/stack exhaustion.

Disabling shadows leaves the failure. The radiance branch still needs an event-level replay to distinguish an inside miss, wrong-instance hit or orientation disagreement. This pass does not establish a model defect or change traversal/spawning to hide it.
