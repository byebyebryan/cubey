Numerical scope and the remaining normal approximation

The GPU probe executes the production fragment shader and exports its scene data before display conversion. Its arithmetic agrees with an independent Snell/Beer control using the observed shading normal. The preserved RGBA8 neutral normal texture tilts that normal by about .318°. At IOR 1.5 the original ideal-sphere direction target is still missed: p99 error is about .514°. The report does not call that target passed.

A two-pixel silhouette band excludes 1.238% of the analytic sphere coverage. Diagnostic captures use RGBA32F; ordinary rendering and media use RGBA16F. Roughness, Fresnel chains, internal reflection and filtering can still produce differences between the renderers.

Boundaries that still matter

The new forward choice is a distant-environment mode. It does not refract neighboring bodies. The sphere exit is an approximation for arbitrary meshes.

Frosted forward and SDF glass use filtered radiance; RT samples rough dielectric transport with bounded paths. A correct central direction does not make these equivalent rough-glass models. Bands on clear RT glass follow its triangulated boundary normals; more samples do not remove that geometry error.

The visible sky omits ground occlusion while the shared lighting probe retains its ground hemisphere. The dark refracted hemisphere comes from that environment convention; no scene ground plane was introduced.

Local scene refraction, new transmission filtering, diffuse GI, caustics and RT clouds remain separate work.

Native operation and source evidence

Choose Transmission source → Environment in the forward workshop, or use --transmission-source environment. Save View retains this setting and the camera; recipes are exported separately. Existing consumers keep the screen default. The new comparison presets select environment explicitly.
