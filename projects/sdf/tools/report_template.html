Windowed controls and acceptance limits

Injected orbit, zoom, pause/reset, two resizes and clean shutdown passed in an isolated Xvfb display, with one geometry build. Physical desktop acceptance remains a separate check.

Deliberate limits

The default atlas holds 262,144 bricks. The main scene selects 778,688 slots and fits below the 2 GiB field budget. The 6,400-stick stress request exceeds that profile and fails without a capture.

Sampled fields can alter grazing silhouettes. The CPU/GPU check reported zero errors outside its interpolation bound and four ambiguous rays in this run. Repeated PNGs are not promised to be bit identical.

This port covers boxes, rendering and procedural presentation. Desktop sculpting, learned generation, GI and terrain-background integration remain later experiments.
