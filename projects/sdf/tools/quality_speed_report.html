Where the extra work helps

Guardian preset depth-error p95 falls from about 0.300 to 0.015 pixel-footprint units with C. At compatible hits, normal-error p95 falls from about 1.27° to 0.064° with C+N. These are approximation errors against the analytical renderer, not physical ground truth.

Where it still fails

ROI panels are 64×64 orthographic query images, enlarged for inspection, not shaded raster captures. The independent coverage image uses mathematical sphere/oriented-box intersections and 16 box-filtered samples per pixel. Nominal width is based on the fixture's physical thin dimension; rotation changes its projected width.

The source fixture suite passes 155 frozen checks. The 12 selected approximate fixture scenes contain 43 rays: all cached variants miss five source hits on the subgrid sphere. C reduces source-depth-contract failures from 27 to two among matched hits, but the subgrid cavity still selects the wrong wall and the tangent case remains inaccurate. C+N therefore fails the proposed detail-preserving profile.

Motion evidence

Each clip has 24 explicit static poses at 12 fps. Tiles: S upper left, C upper right, C+N lower left, analytical lower right. The GPU drains after each captured pose; these clips do not measure interactive frame rate. All pose changes retain existing geometry caches.

The geometry comparison uses 384 native-validated per-frame depth/status snapshots paired with original uninstrumented images. No motion reprojection or automated flicker/human acceptance is claimed. Most boundary p95 values are one pixel; tail failures remain visible.

The costs that faster frames do not remove

Each edit sample changes a real primitive in the full authored scene and waits for the first completed GPU frame. Undo, redo, retry, appearance-only and failed-publication actions are retained separately. Guardian's cached field generation already runs on the GPU; moving a builder to the GPU is not the missing step. Incremental rebuilding is outside this loop.

Requested field/region bytes are distinct from Vulkan allocator residency and total VRAM. Existing staging, program/material buffers and CPU scene copies are not new metadata. CPU region scratch is in the timing receipts. No total-process peak-memory measurement is claimed.

Cached-shadow ablation and compiler evidence

Shadows stay cached in every cached candidate. Disabling shadows in matched native captures separates part of their image disagreement; it does not certify analytical visibility. No new shadow approximation family was introduced.

Driver executable statistics report 96 registers for S/C and 128 for N/C+N, versus 80 for the selected analytical single-material fragment. Static register counts do not measure live occupancy or assign milliseconds. Implausible per-thread local-memory values are retained but excluded.

Decision and next boundary

Keep C and C+N as explicit private preview candidates. C is the inexpensive depth improvement; C+N pays more to clean up normals. Keep sampled/full as the default and analytical rendering as the source-quality reference. Robot can already favor analytical rendering in some views.

If preserving thin features is required, the next investigation should ask how to select source evaluation for uncertain visibility, including cached misses. Same-sign samples and occupancy alone cannot prove a cell contains no feature. That selection policy, automatic preview/settled switching, incremental updates and a windowed root-far port need their own plans.

Evidence and limits

Matched final native timing: three serial, interleaved repetitions per policy/view; 180 frames with 30 warmup and 150 samples per GPU pass. RTX 5070 Ti, NVIDIA 610.57.04. Encoder utilization was 0% at all 348 final frame-timing boundaries; this was still an uncontrolled shared host, with no continuous exclusivity measurement. Earlier publication tests observed 0–50% encoder load. No owned build, capture, test or encoding work overlaps the final timing runs. Do not convert these GPU measurements into interactive FPS promises.

Native diagnostic comparison retains the original four-source-epsilon depth limit and one-degree normal limit. Isolated diagnostic/image mismatches remain unscored; silhouettes exclude two-pixel neighborhoods. The 32 MiB diagnostic cap includes one UV image and packed geometry. No tolerance was widened and no goldens were refreshed.
